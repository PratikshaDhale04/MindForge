# QuizMaster

A simple, animated quiz game for Windows, written in **C++17** with **SFML 3** and
built with **CMake**. Pick a category and a difficulty, answer the questions
before the timer runs out, and your score is saved to a high score table.

```
   +--------------------------------------------------------------+
   |                                                              |
   |            Q U I Z M A S T E R   .   T E S T  ...           |
   |                                                              |
   |                    [ S T A R T   Q U I Z ]                 |
   |                    [ H I G H   S C O R E S ]               |
   |                    [ S E T T I N G S ]                     |
   |                    [ A B O U T ]                           |
   |                    [ E X I T ]                             |
   |                                                              |
   +--------------------------------------------------------------+
```

## 1. What is in the box

| Path              | What it is                                              |
|-------------------|---------------------------------------------------------|
| `include/`        | The header files, one per class                          |
| `src/`            | The `.cpp` files that go with those headers              |
| `assets/fonts/`   | Optional `.ttf` font. A Windows font is used if empty     |
| `assets/sounds/`  | `click.wav`, `correct.wav`, `wrong.wav`                  |
| `data/`           | `scores.txt` and `settings.txt` (created on first run)    |
| `tools/`          | `make_sounds.ps1`, which regenerates the sound effects    |
| `.vscode/`        | Build and run tasks for Visual Studio Code                |
| `screenshots/`    | Pictures of the finished screens                          |
| `build*/`         | Generated by CMake. Safe to delete at any time            |

## 2. How to build and run

The easiest way is the batch file that comes with the project. Open the folder
in File Explorer, double-click **`build.bat`**, and when it says `[OK]` start
the game with **`run_quizmaster.bat`**.

From a command prompt:

```bat
cd E:\quizmaster
build.bat
run_quizmaster.bat
```

To start completely fresh, delete the build folder first:

```bat
build.bat clean
```

### Visual Studio Code

`.vscode\tasks.json` is already set up, so no extension is needed beyond the
C/C++ one for the red squiggles.

1. Open the **`QuizMaster`** folder in VS Code.
2. Press **`Ctrl` + `Shift` + `B`** to build.
3. Press **`F5`** to build and run the game in one go.

Or use the menu: **Terminal -> Run Task...** and pick

| Task                        | What it does                          |
|-----------------------------|---------------------------------------|
| `QuizMaster: build`         | Configure and build (the default)     |
| `QuizMaster: build and run` | Build, then start the game            |
| `QuizMaster: rebuild (clean)`| Delete `build\`, then build again     |

### By hand, if you prefer

```bat
set PATH=C:\msys64\ucrt64\bin;%PATH%
cmake -S . -B build -G Ninja ^
      -DCMAKE_BUILD_TYPE=Release ^
      -DCMAKE_MAKE_PROGRAM=C:\msys64\ucrt64\bin\ninja.exe ^
      -DCMAKE_CXX_COMPILER=C:\msys64\ucrt64\bin\g++.exe ^
      -DQUIZMASTER_DEP_PREFIX=C:/msys64/ucrt64
cmake --build build
build\bin\QuizMaster.exe
```

`QUIZMASTER_DEP_PREFIX` is the folder that contains SFML. Change it if your
toolchain lives somewhere else.

## 3. The screens

| Screen      | What it does                                                        |
|-------------|---------------------------------------------------------------------|
| **Home**    | Start, high scores, settings, about, exit                            |
| **Name**    | Type a name with the keyboard, then `Enter` or `CONTINUE`            |
| **Category**| `C++`, `Python`, `SQL`, `General Knowledge` - shows how many questions each holds |
| **Difficulty** | `Easy`, `Medium`, `Hard` - each has its own length and timer       |
| **Quiz**    | The question, four answers, a timer and a progress bar               |
| **Result**  | Score, accuracy, a breakdown, and where the score was saved           |
| **High scores** | The saved table, with a filter per category                      |
| **Settings** | Sound, animations and theme, all saved to `data/settings.txt`       |
| **About**   | What the project is and what it can do                               |

### Keys

| Key        | Does                                       |
|------------|--------------------------------------------|
| `A` `B` `C` `D` | Answer the question on the quiz screen |
| `Enter` / `Space` | Press the highlighted button        |
| `Esc`      | Go back one screen                         |

Everything can also be done with the mouse, which is the easiest way to try
the game out.

## 4. The questions

60 questions in total, held in one place: `src/Question.cpp`. They are compiled
into the program, so nothing has to be read from disk at start-up.

| Category           | Topic                                     |
|--------------------|-------------------------------------------|
| `C++`              | Language rules, classes, memory           |
| `Python`           | Lists, dictionaries, generators           |
| `SQL`              | Queries, joins, normalisation, ACID       |
| `General Knowledge`| Science, geography, history, the body     |

Each category has 5 **Easy**, 5 **Medium** and 5 **Hard** questions. A quiz
takes every question of the chosen category and shuffles them, then stops once
the difficulty's question count is reached.

| Difficulty | Questions | Seconds per question |
|------------|-----------|---------------------|
| Easy       | 5         | 30                  |
| Medium     | 8         | 20                  |
| Hard       | 12        | 15                  |

The two numbers live in `include/Quiz.h` as `EASY_QUESTIONS` and `EASY_TIME`
and their `MEDIUM_` and `HARD_` counterparts. The Difficulty screen reads the
same constants for its labels, so the cards can never disagree with the quiz.

### Adding your own questions

One question is one `makeQuestion(...)` call at the bottom of `buildBank()` in
`src/Question.cpp`:

```cpp
bank.push_back(makeQuestion("C++", "Easy",
    "Which operator is used to delete an object allocated with new?",
    "delete", "free", "sizeof", "release",      // A, B, C, D
    'A',                                       // which one is right
    "It releases the memory the pointer was using."));
```

The parts are, in order:

1. `category` - the string the category screen shows
2. `difficulty` - `Easy`, `Medium` or `Hard`
3. the question text
4. four possible answers, `A` to `D`
5. the correct letter
6. an explanation, shown after answering

Rebuild and the new question is in. The count under each category card updates
by itself, because `availableCategories()` and `countQuestions()` read the same
list.

## 5. The sounds

`assets/sounds` holds three small files:

| File           | Played when                       |
|----------------|-----------------------------------|
| `click.wav`    | any button is pressed             |
| `correct.wav`  | an answer is right                |
| `wrong.wav`    | an answer is wrong or runs out    |

They are ordinary 16 bit WAV files, so they can be replaced with any sounds of
your own - just keep the same three names. If a file is missing the game says so
in a message and carries on silently; nothing breaks.

To regenerate the original three:

```bat
powershell -ExecutionPolicy Bypass -File tools\make_sounds.ps1
```

## 6. The look

- **Light** by default, **dark** available on the Settings screen.
- Screens slide in when you move to them, and fade in when they first appear.
- Buttons glow, tilt towards the cursor and ripple where you press them.
- Correct and wrong answers are framed in green and red, and the answer text
  pops in.
- The timer blinks red during the last few seconds.
- A small sparkle drifts across the background.
- **Notifications** appear in the top right corner. The layout leaves that
  corner empty on every screen, so a message can never cover a button.

All of it can be switched off at once with **Settings -> Animations**, which
makes the game completely still.

## 7. Files it writes

Two files, both under `data\`. Both start out as nothing but a few `#` comment
lines, and both are filled in by the game:

- **`scores.txt`** - the high score table, best ten scores kept. It gains a line
  every time a quiz is finished.
- **`settings.txt`** - sound, animations and theme. It is rewritten every time
  something is changed on the Settings screen.

Neither file ever needs to be edited by hand. Deleting them is safe: the game
simply starts with a fresh set.

Each file is written to a `.tmp` next to it first and only then moved into
place, so a write that is interrupted cannot destroy the previous contents.
Lines beginning with `#` are treated as comments and skipped, so notes can be
written in either file.

## 8. Troubleshooting

**"SFML 3 was not found"** - pass `-DQUIZMASTER_DEP_PREFIX=` pointing at the
folder that holds `include\` and `lib\`, for example `C:/msys64/ucrt64`.

**`QuizMaster.exe` will not start** - the MinGW runtime DLLs have to be found.
Running `run_quizmaster.bat` does that for you; `build.bat` also copies them
next to the `.exe`, so a double click should work too.

**No text on screen** - no font could be loaded. Put any `.ttf` file into
`assets\fonts` and start again.

**No sound** - check that the three `.wav` files are in `assets\sounds`, and
that Settings -> Sound is on.

**A setting or a score does not stick** - both files are saved through a
`.tmp` file that is then moved into place. If something is holding the file
open, or the folder is read-only, the game says so in a red notification and on
the console rather than pretending the write worked.

**Stuck on a black screen** - the `build` folder can be deleted at any time;
`build.bat` recreates it from scratch.
