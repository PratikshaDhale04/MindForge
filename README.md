# MindForge

MindForge is an animated desktop quiz application developed using **C++17, SFML 3, and CMake**. It provides an interactive platform to test programming knowledge through timed quizzes, multiple difficulty levels, and score tracking.

## Features

- Multiple categories: C++, Python, SQL, and General Knowledge
- Three difficulty levels: Easy, Medium, and Hard
- Timer-based quizzes with shuffled questions
- Animated user interface with sound effects
- Score tracking and leaderboard
- Light and dark themes
- Customizable settings and keyboard controls

## Tech Stack

- **Language:** C++17
- **Graphics & Audio:** SFML 3
- **Build System:** CMake
- **Compiler:** MinGW-w64

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/PratikshaDhale04/MindForge.git
cd MindForge
```

**2. Build the application**

```bat
build.bat
```

**3. Run the application**

```bat
run_quizmaster.bat
```

**Requirements:** Windows, a C++17-compatible compiler, CMake, Ninja, and SFML 3.

## Keyboard Controls

| Key | Action |
|---|---|
| A, B, C, D | Select an answer |
| Enter / Space | Activate the highlighted button |
| Esc | Return to the previous screen |
